# Product art

One card per starter-catalog SKU (`<sku lowercase>.svg`), referenced by the API's
catalog pack as `<STOREFRONT_URL>/art/<file>`. Generated by
`scripts/generate-product-art.mjs`: brand colour + brand mark + denomination.

Marks come from [Simple Icons](https://simpleicons.org) (CC0 path data). The
marks remain trademarks of their owners and are used only to identify the
product being sold. Brands Simple Icons does not carry are set in type instead.

The owner can replace any image from the admin dashboard (product → image
URL); a pack never overwrites an image that is already set.
