## 7. الناقص قبل هذا العمل

- لا جدول للدول ولا لوسائل الدفع المكتشفة بمصادرها وتاريخ التحقق منها؛ الدول ثابتة في كود المتجر.
- لا مكان واحد للاكتشافات مع حالة (موافقة/رفض/تأجيل) وسجل قرارات وسجل تشغيل الوكلاء.
- لا وكلاء Claude Code معرّفون في المستودع (`.claude/agents` لم يكن موجودًا).
- لا فحص دوري للقراءة والتحليل في GitHub Actions غير live-check و nightly.
